기존 나라장터 개업일 조회 기능 및 445개 업체 목록 유지.
기존 개업일 조회 브라우저 저장소(komsco-open-date-v6)를 그대로 사용합니다.

[여성기업/장애인기업]
공식 인증서 API: https://www.data.go.kr/data/15062581/openapi.do
나라장터 API와 별도 활용신청. 상세기능에서 해당 API 각각의 요청주소를 확인해 입력합니다.
정확한 두 오퍼레이션 URL을 사전에 검증할 수 없어 프로그램에 임의로 하드코딩하지 않았습니다.
인증서 API 개발계정 기본 일일 트래픽 100건: 445업체*2=890회 이상의 호출은 운영계정 트래픽 증설이 필요합니다.
조회기준일, 인증 유효시작·종료일로 판단. 오류/미조회=미확인(미인증이 아님).

[사회적기업]
한국사회적기업진흥원 공식 인증기업 현황을 CSV/TXT로 취득한 후, 사업자등록번호와 인증상태·유효기간 필드를 갖춘 자료로 변환하여 업로드.
예비사회적기업은 정식 인증 사회적기업으로 보지 않습니다. 원본에 인증상태 또는 유효기간이 없는 경우에는 인증 확정을 하지 않습니다.

TXT/CSV 업로드 헤더: 사업자등록번호, 구분, 인증상태, 유효시작일, 유효종료일
인증상태는 "인증" 등 긍정표시여야 하며, 유효종료일이 없으면 미확인됩니다.
기존 445개 개업일 조회는 별도 작동합니다. 결과 통합 TXT 버튼으로 내려받습니다.
