나라장터 개업일 자동조회 — 모바일 수정판

[이전 실패 원인]
휴대폰에서 HTML을 다운로드해 열면 주소가 content:// 또는 file:// 로 표시됩니다.
기존 웹앱은 로컬 Python 서버의 /api/lookup 엔드포인트를 호출하므로 모바일 파일 직접 열기로는 작동하지 않습니다.

[모바일 실행을 위한 배포 — Cloudflare Workers]
1. PC 브라우저에서 https://dash.cloudflare.com/ 로그인(무료 계정 가능).
2. Workers & Pages > Create > Worker 만들기.
3. Edit Code를 누르고 기본 코드를 모두 지운 뒤 cloudflare-worker.js 전체를 붙여넣습니다.
4. Deploy(배포)를 누릅니다.
5. 생성된 https://...workers.dev 주소를 휴대폰 Chrome에서 엽니다.
6. 공공데이터포털 https://www.data.go.kr/data/15129466/openapi.do 에서
   조달청 나라장터 사용자정보 서비스 활용신청 후 발급된 디코딩(Decoding) 인증키를 입력합니다.
7. 반드시 '1건 연결 시험'부터 눌러 정상 결과인지 확인하고 전체 자동조회를 실행합니다.
8. 결과는 휴대폰 브라우저에 저장되고 TXT 다운로드로 보관할 수 있습니다.

[주의]
- index.html은 화면 코드 확인용입니다. 휴대폰에서 이 파일을 직접 열면 자동조회는 동작하지 않습니다.
- 별도 Python 설치는 필요 없으며 배포된 HTTPS 주소에서 스마트폰으로 사용할 수 있습니다.
- 실제 인증키가 없으므로 실조회 결과는 검증하지 못했습니다.
- 이 프로그램에서 사용하는 API 필드는 개업일시(opbizDt)이며 법인 설립등기일과 다를 수 있습니다.
- API 인증키는 입력할 때마다 사용하며 브라우저 저장소에 저장하지 않습니다.
- 조회 결과(업체명·사업자번호·개업일)는 휴대폰 브라우저 내부에 저장됩니다. 공유 기기 사용을 피하세요.
- 모바일 브라우저가 백그라운드로 전환되면 진행이 중단될 수 있습니다. 화면을 켜 둔 상태로 이용하세요.
- 사용량·요금 및 데이터 공개 범위는 Cloudflare 계정 설정을 확인하세요.
- Cloudflare workers.dev URL을 타인에게 공유하면 앱 화면이 공개됩니다. 기관 내부 사용 시 접근 제한을 별도로 설정하세요.
