V20 중단 지점 이어 조회
1. GitHub g2b 저장소의 worker.js를 이 파일로 교체. index.html은 배포하지 않음.
2. Cloudflare G2B_API_KEY Secret 유지하고 Production 배포 확인.
3. 기존과 같은 브라우저 및 사이트 주소로 접속. 완료된 100건은 localStorage에서 복구됩니다.
4. 중단 지점부터 이어 조회 클릭. API HTTP 429가 지속되면 API 호출한도가 회복될 때까지 중지됩니다.
5. 조회결과 백업(JSON)을 저장하면 브라우저 데이터 삭제/기기 변경에 대비할 수 있습니다.
주의: 호출한도를 회피하지 않습니다. 재개 시에도 일일 한도 초과 상태면 다시 중단됩니다.
주의: 신규 Worker 코드 배포시 로컬 저장기록을 삭제/초기화하지 마세요.
