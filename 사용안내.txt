나라장터 V5: 서버 응답 형식 오류 진단판

1. Cloudflare Workers & Pages에서 g2b Worker의 Edit code를 엽니다.
2. cloudflare-worker.js 전체를 복사하여 기존 코드를 전부 교체 후 Deploy 합니다.
3. 배포 사이트를 Ctrl+Shift+R로 강력 새로고침합니다.
4. ‘서버 연결 점검’을 누르면 HTTP 200 및 version V5가 표시되어야 합니다.
5. 정상이라면 API 인증키를 입력하고 ‘1건 연결 시험·진단’을 누릅니다.
6. 화면의 진단 내용을 공유하되 API 인증키는 공유하지 마세요.
7. 성공 날짜 1건이 확인되기 전 전체 자동조회는 진행하지 마세요.

주의: index.html을 별도 업로드하는 것이 아니라 cloudflare-worker.js를 배포해야 합니다.
정상 데이터 조회는 실제 API 인증키가 없어 검증되지 않았습니다.
개업일시는 법인등기상 설립일과 다를 수 있습니다.
